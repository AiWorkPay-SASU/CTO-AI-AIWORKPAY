# Kit documentaire CTO IA

Ce kit est destiné à une **équipe de développement logiciel multiagents**. Il ne décrit pas la workforce métier AiWorkPay.

## Documents
1. 01_PRD.md — objectifs produit et exigences
2. 02_TRD.md — architecture et contraintes
3. 03_APPFLOW.md — parcours et écrans
4. 04_UI_UX_DESIGN.md — design system
5. 05_BACKEND_SCHEMA.md — données, API et permissions
6. 06_IMPLEMENTATION_PLAN.md — jalons et missions
7. ../AGENTS.md — règles des agents
8. ../TASKS.md — suivi des missions
9. ../SECURITY.md — sécurité et autorisations

## Processus
Le fondateur définit l'objectif ; le CTO fait préparer les spécifications, vérifie leur cohérence, demande les arbitrages, délègue les tâches, suit les preuves, fait contrôler par QA/Sécurité puis propose la livraison.

Les fichiers sont des **modèles à renseigner**. Ils ne constituent ni une orchestration autonome opérationnelle ni des spécifications approuvées pour une application particulière.
